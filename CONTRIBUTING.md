# Contribution workflow

1. Fork this repository.
2. Clone your fork and create a focused branch, for example `fix/refund-validation`.
3. Read STUDENT_PROBLEM_STATEMENT.md and inspect the relevant source and tests.
4. Run `python -m pytest -q` after each meaningful change.
5. Make small, understandable commits.
6. Open one pull request from your fork to this original repository. Do not merge it.
7. In the PR description, explain the root cause, behaviour changed, tests run and any limitations.
8. Check the GitHub Actions result attached to the pull request.

## Individual-work and AI policy
AI chatbots, AI coding assistants, generated code/tests and solution-sharing are prohibited during this evaluation. Ordinary Python reference documentation is allowed. Do not paste challenge code or data into external services. You must explain the submitted code and make a small live change if asked.
