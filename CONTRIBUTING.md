# Contribution workflow

1. Fork this repository.
2. Clone your fork and create a focused branch, for example fix/refund-validation.
3. Read the issue ticket and problem statement before changing code.
4. Run python -m pytest -q after each meaningful change.
5. Commit your own work in small, understandable steps.
6. Open a pull request from your fork to this original repository. Do not merge it.
7. In the PR description, explain the root cause, fix, tests run and any limitations.
8. Check the GitHub Actions run attached to the pull request.

## Integrity and AI policy
AI chatbots, AI coding assistants, generated code, generated tests and solution-sharing are prohibited during this evaluation. Ordinary language documentation and Python reference materials are allowed. Do not paste challenge code or data into external services. You must be able to explain the submitted code and make a small live change without outside assistance.
